TypeShi - Phase 5 Part 1
Contributor: Daniel
=========================

Language: TypeScript (Node.js, in-memory only)

---

WHAT WAS DONE
---------------------
Two use cases were implemented for this phase:

1. Generate Test Text (1_Generate_Test_Text/)
   - Class: GenerateTestTextUseCase
   - Accepts a word count, picks random words from a word bank,
     and returns a GeneratedTestText object with a textId,
     content string, wordCount, and createdAt timestamp.

   - Validates that wordCount > 0 and word bank is not empty.

2. Display Test Results (2_Display_Test_Results/)
   - Class: DisplayTestResultsUseCase
   - Accepts a TestResult object, validates it, and returns a
     DisplayedTestResult object that includes all result fields
     plus a summaryMessage based on performance.

   - Validates wpm >= 0, accuracy between 0-100, totalChars >= 0.

---

SHARED FILE (common data)
-----------
CommonData.ts
   - Contains all shared interfaces: WordBank, GeneratedTestText,
     TestResult, DisplayedTestResult.

   - Contains DEFAULT_WORD_BANK, a seeded list of 60 common words
     used by GenerateTestTextUseCase just out of the box.

---

HOW TO RUN THE TESTS
---------------------
Make sure Node.js and ts-node are installed if not already
Those who have done it last phase should be able to just do what they did before.

Install ts-node if needed:
    npm install -g ts-node typescript

Run the manual test file from this folder:
    npx ts-node test.ts

The test file covers:
   - Normal text generation (10 words, 25 words)
   - Invalid input handling (wordCount = 0)
   - High and low performer result display
   - Invalid accuracy and negative WPM error cases
